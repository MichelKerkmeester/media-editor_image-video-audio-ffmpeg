feat(media-editor): ask first and run the skill through media-editor

Context: a clear batch request went straight to work, leaving four
results under imported names, sometimes in four numbered folders. In
Claude Code the skill depended on an MCP server the plugin had to start,
and a model asked for a conversion often skipped the skill and ran cwebp
or ffmpeg itself. The plugin no longer registers an MCP server: Claude
Code users get the media-editor command in the Bash tool instead, and
the Desktop extension keeps MCP unchanged.

  maxBytes on image_convert as a size cap that never resizes

  rule out cwebp, sips and ImageMagick in ALWAYS 1
