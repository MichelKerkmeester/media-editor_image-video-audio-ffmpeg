# v1.0.0.0, Readable Names and a Tidy Export Folder

A result now gets a name that says what it shows, and a single file lands straight in `media files/export/` instead of a folder of its own. The server gained a rename tool and a content preview to make both work, and the Human Voice Rules are gone from the system.

## Version Numbering

This is the first stable release. Every earlier release is renumbered as a pre-release: v1.a.b.c became v0.(a+1).b.c, so the previous release, once v1.7.0.0, is now v0.8.0.0. The Project kernel moves to v1.0.0 the same way, and the MCP server, the Desktop extension and the plugin move from 0.1.0 to 1.0.0.

## Why This Release

Imported media often carries a name that says nothing, such as `CleanShot 2026-10-03 at 16.46.54.png` or a chat placeholder like `[Image #2]`, and every result inherited it with an operation word on the end: `CleanShot 2026-10-03 at 16.46.54-converted.webp`. Every call also wrote a new numbered folder, so four quick conversions left four folders holding one file each. Asked to fix a name, Claude Desktop could only say that no tool renames a file.

The Human Voice Rules were written for prose deliverables. The Media Editor delivers media files and a short path-led reply, so two Knowledge cards, two references, a self-scan step and a linter cost tokens on every answer and checked nothing the system produces.

## What's New at a Glance

- **A readable name for every result.** The skill and the kernel propose two to five words from what the media shows and apply them only after the user confirms. A name the user already gave is used as given.
- **One file, no folder.** A one-file result lands straight in the export folder. Several files from one operation still get one numbered folder, and an optional folder is asked about first.
- **`media_rename`.** A new tool renames a result inside the export folder, keeps its extension and its folder, and never overwrites.
- **`fileName` and `subfolder`.** Every writing tool except `video_hls_ladder` takes both, so a result is named and placed in the same call that writes it.
- **Content preview.** `image_probe` and `media_probe` take `preview: true` and return a small JPEG, or one video frame, to name the file from.
- **Guided setup.** Without the tools, the system still answers, then offers once to walk the user through installing the extension, the plugin or ffmpeg, one step at a time, with the extension downloaded from the latest GitHub release.
- **Human Voice Rules removed.** The references, the Knowledge cards, the self-scan step, the attestation field and the linter are gone.

## Server

#### Placement Follows the Result

The registry adds `fileName` and `subfolder` to every tool that writes into one folder and hands the handler a context that carries them. One file goes to the export folder itself, several files get the next `NNN - description/` folder, `subfolder` overrides either default and `video_hls_ladder` always keeps its own folder. A taken name in the export folder moves on to `-2`, `-3` and so on, because an earlier result there belongs to the user. A failed call removes only what it wrote and never the export folder.

&nbsp;

#### A Rename Tool

`media_rename` takes the path of a result and a new name. The name is slugged like a folder name, the extension and the folder stay, and the move is a hard link followed by an unlink, so an existing file is never replaced. A file outside the export folder returns `PATH_NOT_ALLOWED`. The server now has 40 tools.

&nbsp;

#### Preview to Name From

`preview: true` on `image_probe` returns the image at most 512 pixels on its longest side. On `media_probe` it returns one frame a quarter of the way into a video. Audio has no picture, so the probe answers with a warning instead. A preview that fails is a warning too, because the metadata is still the answer.

## Skill and Project

#### Propose, Confirm, Then Write

`SKILL.md` gains a File Naming section, ALWAYS 8 and NEVER 8, and `AGENTS.md` and the kernel carry the same rule. With the tools or ffmpeg the runtime asks before it writes, in the same question as any other clarification. Advice writes no file, so it puts the proposed name into the command without waiting.

&nbsp;

#### The Export Protocol Splits by File Count

The export protocol in `SKILL.md`, `AGENTS.md` and the kernel now reads one file into `media files/export/`, several into one numbered folder. `references/tools.md`, the two operation references and the interactive flow describe `fileName`, `subfolder`, `media_rename` and `preview`, and each Knowledge mirror took the same change byte for byte. Replies report the path the tool returned, which is a file for one result.

&nbsp;

#### A Guided Setup When the Tools Are Missing

The new `references/setup.md` and its Knowledge mirror, `Media Editor - Reference - Setup`, find where the user is, then give one step at a time: the extension file for each computer from the latest release, its **Folders Media Editor may open** and **Output folder** settings, the **+ > Connectors** switch, ffmpeg through `media_setup_ffmpeg` with consent, the plugin and local ffmpeg. The tool check in `SKILL.md`, `AGENTS.md` and the kernel offers it once after the advice answer, and calls the setup done only when `media_health` answers. `INSTALL-GUIDE.md`, `USER-GUIDE.md` and the root README now point at the release instead of a build or the maintainer.

&nbsp;

#### Human Voice Rules Leave the System

`references/hvr-core.md`, `references/human-voice-rules.md` and their two Knowledge cards are deleted, so with the new Setup reference the Project holds seven Knowledge files. The kernel drops the HVR Self-Scan section, its delivery step and the `HVR = checked` attestation field, and the router's always-load list is `references/media-framework.md` alone.

## Testing

#### Server Tests

New suites cover the export folder default, the `-2` rule, `fileName`, `subfolder` both ways, an audio result in the export folder, a failed call that leaves earlier results alone, the listed schemas, `media_rename` and both previews. The existing suites pin `subfolder: true` through the test client, so they keep checking the numbered folders.

&nbsp;

#### Gates Without the Voice Checks

`benchmark/gates/rule_parity.py` reads six pairs and five rules, and `benchmark/grader/check_report.sh` runs the twin-scenario check alone now that the reply linter is gone. The playbook scenarios that write a result gained a naming turn, and two new scenarios cover the name proposal and the export folder without a subfolder. `PRO-002` covers the setup offer in a browser Project, and `STV-001` now expects the offer too.
