# v0.4.0.0, Exact Commands and One Project Kernel

Mode detection moves from substring matching to exact `$token` commands and word-boundary keywords. `SKILL.md` Section 2 adds Phase Detection, so the router carries the full five-part contract. The skill mirror is removed from Project Knowledge because the advisory kernel is the authoritative skill in a Project.

## What's New at a Glance

- **Phase Detection completes the five-part contract.** `SKILL.md` Section 2 gains the missing Phase Detection subsection, so the router carries Primary Detection Signal, Phase Detection, Resource Domains, Resource Loading Levels and Smart Router Pseudocode.
- **Mode detection uses exact commands and word-boundary keywords.** The pseudocode's mode detection moves from substring matching to exact `$token` commands and word-boundary keywords, so `$img` never fires inside a longer word and `photo` never matches "photography". An explicit command wins outright, so `$audio from this video` binds Audio Mode, not Video.
- **The advisory kernel is rebuilt to match the skill.** `Custom Instructions.md` is rebuilt as a faithful, Project-adapted mirror of the hardened skill, with the same five-part routing, the full ALWAYS, NEVER and ESCALATE rules, the Tool Verification Gate, MEDIA Flow, Format And Quality Intelligence and Fallback Coverage. It is framed advisory-only and is the authoritative skill in a Project.
- **The skill and the kernel take new versions.** `SKILL.md` moves from 0.3.0 to 0.4.0 and `Custom Instructions.md` moves from 0.2.0 to 0.3.0, aligned to Skill 0.4.0. Reference and asset mirrors are unchanged.
- **The Project Knowledge skill mirror is removed.** `Media Editor - System - Skill - v0.3.0.md` is removed from `claude project/knowledge/`, undeclared in `claude-project.sync.json` and dropped from `mirrors` and `sourceCoverage`. `expectedKnowledgeCount` moves from 7 to 6 and six files remain in `claude project/knowledge/` against that declared count.
- **Media behavior stays in place.** Media rules, format intelligence, MEDIA thinking, the export protocol and the fallback direction are unchanged in substance.

## Upgrade

A named-human kernel review is still required before release, because `SKILL.md` stays a contract input. `check --system media-editor --run-validators` returns exit 3 with only `KERNEL_REVIEW_REQUIRED`.
