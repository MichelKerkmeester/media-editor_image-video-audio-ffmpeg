# v0.8.0.0, Tool Groups and the Router Contract

Each mode now names the Media Editor tools it calls and the ffmpeg route it falls back to, and one router file is the authority that the skill, the kernel and the checks all read.

The skill package also moved onto the sk-doc skill contract: a name that matches its folder, a four-part version, generated leaf manifests in place of `description.json`, and a playbook that covers every mode and alias.

## Why This Release

The skill and the Project still described the two third-party servers the Media Editor's own server replaced. Two references carried ffmpeg recipes under the old server names, and the router bound every mode to `"ffmpeg"` even with 39 tools connected. The router also lived in three copies, `SKILL.md`, the kernel and the oracle, and nothing compared them.

The package itself failed the sk-doc validators: a three-part version, a name that differed from the folder, a forbidden `description.json`, no leaf manifests and sentence-case headings. The playbook had no scenario for Repair Mode, the aliases or any tool other than `image_resize`.

## What's New at a Glance

- **Every mode names its tools.** Image binds `image_*`, Video `video_*`, Audio `audio_*`, HLS `video_hls_ladder` and Repair `media_probe` then `media_repair`, each with an ffmpeg fallback.
- **One router file.** `references/router-contract.md` holds the router as running Python, and the kernel ends with the same code.
- **The first command wins.** With two commands in one request, the first one in the text decides the mode.
- **References named for what they hold.** The image and the video and audio operation references replace the two named after retired servers, beside a reference for all 39 tools.
- **Kernel v0.8.0 and eight Knowledge files.** Upper-case headings, a Project Knowledge section, a tool delivery block and the Router Code at the end.
- **A package that meets the sk-doc contract.** The skill is `sk-media-editor` at v0.8.0.0, with generated leaf manifests and upper-case headings throughout.
- **27 playbook scenarios.** New scenarios cover Repair Mode, the aliases, the first-command rule, the ffmpeg consent flow and an error code hand-off.

## Tools and Routing

#### Every Mode Binds a Tool Group

The router's tool field now carries the tools each mode calls when the Media Editor tools are connected: `image_*`, `video_*`, `audio_*`, `video_hls_ladder`, and `media_probe` then `media_repair` for Repair. Interactive binds none until its one question names the media type. The fallback is ffmpeg, with ffprobe then ffmpeg for Repair.

&nbsp;

#### One Router, Checked Three Ways

`references/router-contract.md` is the router as running Python, and `SKILL.md` points at it. The Project kernel ends with Section 8, Router Code, the same code with its comments removed. `benchmark/router/differential.py` holds the contract, the oracle and the kernel copy equal on copy, table, behavior and coverage parity, across three host states: tools connected, ffmpeg only and neither.

&nbsp;

#### The First Command Decides

`$aud strip the track from this $video` is now Audio. Before, the earlier row in the router table won, so `$video` beat `$aud`. `$interactive` and `$int` route too: both were documented and missing from the router table, so they fell through to keyword scoring.

## References and Knowledge

#### Operation References Renamed

`references/mcp-imagician.md` is now `references/image-operations.md`, and `references/mcp-video-audio.md` is now `references/video-and-audio-operations.md`. Each lists its tools with parameters and defaults first, then the ffmpeg recipes. `assets/hls-video-conversion.md` opens with `video_hls_ladder` ahead of the ffmpeg command pack.

&nbsp;

#### A Reference for All 39 Tools

`references/tools.md` lists every tool, the consent flow behind `media_setup_ffmpeg`, the 15 error codes with what to do about each, the server settings and the four operations no tool covers.

&nbsp;

#### Kernel v0.8.0 and Eight Knowledge Files

The kernel takes upper-case section headings like the rest of the fleet, a Project Knowledge consultation section, a tool delivery block that names an error code instead of presenting a failed call as a run, and the Router Code section at the end. Image Operations v0.213, Video And Audio Operations v0.213, Media Editor Tools v0.100 and HLS Video Conversion v0.112 replace MCP Imagician v0.211, MCP Video Audio v0.212 and HLS Video Conversion v0.111.

## Skill Package

#### Name and Version Follow the Folder

`SKILL.md` declares `name: sk-media-editor` and `version: 0.8.0.0`, and `graph-metadata.json` carries the same `skill_id`, the `sk-util` family and ten intent signals. The Claude Code plugin copies the skill to `skills/sk-media-editor/` and replaces its whole `skills/` folder on every build, so a copy under the old name never ships beside the new one.

&nbsp;

#### Generated Leaf Manifests

`leaf-manifest.config.json` names the routed folders, and the sk-doc gate generates `leaf-manifest.json` and `leaf-aliases.json` from it. `description.json` is gone, because the contract forbids it on a standalone skill and nothing read it.

&nbsp;

#### Shared Cards Travel as Copies

`references/hvr-core.md` and `references/human-voice-rules.md` are byte copies of the shared cards instead of links that climb out of the repository, so a clone of the public repository carries them. The parity declaration names both as vendored copies and holds each one to its card byte for byte.

&nbsp;

#### Headings and a Repository README

Every numbered heading in `SKILL.md`, `README.md`, the references and the HLS asset is upper case, which clears every document-validator failure. The system root carries its own `README.md` for the public repository.

## Testing

#### Eight New Scenarios

The playbook grows from 19 to 27 scenarios across 18 categories. `SCR-003` and `PRP-002` test the first-command rule on both runtimes, `SCR-004` the `$vid` alias, `SCR-005` the Interactive command, `SRM-001` and `PRM-001` Repair Mode, `STV-002` the ffmpeg consent flow and `STV-003` a `PATH_NOT_ALLOWED` hand-off.

&nbsp;

#### A Stricter Identity Handover

`SID-001` now passes only when the reply names `AGENTS.md` as its instruction set, a string the whole Project load surface never contains, alongside the real written export.
