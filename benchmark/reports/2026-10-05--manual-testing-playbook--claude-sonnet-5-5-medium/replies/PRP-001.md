**Audio Mode, advice route.** The Media Editor tools aren't connected to this Project, and it can't run ffmpeg. Nothing has run and no file exists yet. You'd run the command yourself.

**Run this** (set the input path to your demo video; the output name is a proposal you can change):

```bash
ffmpeg -version   # confirm ffmpeg is installed
ffmpeg -encoders | grep libmp3lame   # confirm the MP3 encoder
mkdir -p "media files/export"
ffmpeg -i "/path/to/product-demo.mp4" -vn -c:a libmp3lame -b:a 192k "media files/export/product-demo-podcast.mp3"
```

- **Settings:** `-vn` drops the picture. `libmp3lame` at 192 kbps plays in every podcast app. If the demo is mostly speech, 96k to 128k mono gives much smaller files that still sound fine.
- **Result lands in:** `media files/export/product-demo-podcast.mp3`, relative to where you run the command.
- **Check this:** run `ffprobe "media files/export/product-demo-podcast.mp3"`. It should show an mp3 audio stream at about 192 kb/s and a duration matching the video. Then listen to the start and end.
