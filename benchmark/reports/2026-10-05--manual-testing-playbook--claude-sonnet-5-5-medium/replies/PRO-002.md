## Reply

**Image mode.** The Media Editor tools aren't connected in this conversation, so nothing ran. This is advice only.

**Run this** (set `INPUT.jpg` to your hero photo's path):

```bash
mkdir -p "media files/export"
ffmpeg -i INPUT.jpg -vf scale=800:-1 -q:v 5 "media files/export/blog-hero-800w.jpg"
```

- **Resize:** `scale=800:-1` sets the width to 800 px and works out the height from the aspect ratio.
- **Quality:** `-q:v 5` is a good JPEG setting for web display. Lower numbers give better quality and bigger files.
- **Name:** `blog-hero-800w.jpg` is a proposed name. Change it if you want something else. If you tell me what the photo shows, I can suggest a more descriptive one.
- **Format:** I kept JPEG because it works everywhere. WebP at about 85% quality gives smaller files, but it needs an ffmpeg build with a WebP encoder. Check with `ffmpeg -encoders | grep libwebp` before using it.
- **Small sources:** if the original is narrower than 800 px, this will enlarge it. Tell me if you'd rather it stayed as it is.

**Result lands in:** `media files/export/blog-hero-800w.jpg`

**Check this:**
```bash
ffprobe -v error -show_entries stream=width,height -of default=noprint_wrappers=1 "media files/export/blog-hero-800w.jpg"
```
The width should read 800. Also open the file to check it looks sharp.
