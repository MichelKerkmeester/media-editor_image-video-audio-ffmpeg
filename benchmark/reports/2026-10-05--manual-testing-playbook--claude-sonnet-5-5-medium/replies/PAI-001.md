## Reply

**Run this** (set `INPUT` to your PNG's path):

```bash
INPUT="/path/to/your-hero.png"

# 1. Check that your ffmpeg can encode WebP (it should list libwebp)
ffmpeg -encoders 2>/dev/null | grep libwebp

# 2. Create the export folder and write the WebP
mkdir -p "media files/export"
ffmpeg -i "$INPUT" -vf "scale='min(1920,iw)':-2" -c:v libwebp -quality 85 "media files/export/homepage-hero.webp"
```

If step 1 prints nothing, use JPEG instead:

```bash
ffmpeg -i "$INPUT" -vf "scale='min(1920,iw)':-2" -q:v 5 "media files/export/homepage-hero.jpg"
```

I used `homepage-hero` as a working name because I don't know what the photo shows. Rename it however you like.

**Why these settings:**
- **Format:** WebP at 85% usually shrinks a 6 MB photo PNG to a few hundred KB with no visible loss. Browsers all support it.
- **Width:** It caps the width at 1920 px and never upscales a smaller image. That is enough for most full-width heroes. If your hero is narrower, tell me the display width and I'll adjust.
- **Transparency:** I assumed the photo has none. If it does, the WebP keeps it, but the JPEG fallback would not.

**Result lands in:** `media files/export/homepage-hero.webp`

**Check this:** Run `ffprobe "media files/export/homepage-hero.webp"` and confirm the width is 1920 or less. Then compare file sizes with `ls -lh`. Open it in a browser and look at the edges and sky for banding. If you see any, raise `-quality` to 90. For a smaller file, lower it to 75–80.
