Converting the keynote recording to a four-quality HLS ladder with installed ffmpeg.

```bash
ffmpeg -i keynote.mp4 \
  -filter_complex "[0:v]split=4[v1][v2][v3][v4]; \
  [v1]scale=w=1920:h=1080[v1out]; [v2]scale=w=1280:h=720[v2out]; \
  [v3]scale=w=854:h=480[v3out]; [v4]scale=w=640:h=360[v4out]" \
  -map "[v1out]" -c:v:0 libx264 -crf 23 \
  -map "[v2out]" -c:v:1 libx264 -crf 23 \
  -map "[v3out]" -c:v:2 libx264 -crf 23 \
  -map "[v4out]" -c:v:3 libx264 -crf 23 \
  -f hls -hls_time 2 -hls_playlist_type vod \
  -master_pl_name "master.m3u8" \
  "media files/export/006 - keynote-hls/%v/playlist.m3u8"
```

Result lands in `media files/export/006 - keynote-hls/` with a master playlist and one folder per quality.

Check this: run `ffprobe "media files/export/006 - keynote-hls/master.m3u8"` and confirm all four variants list, then play the master playlist in a browser to confirm adaptive switching.

The saved path leads this reply. Verify the folder holds four quality directories plus the master playlist before treating the conversion as done.
